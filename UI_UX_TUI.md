## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                         App State                           │
├─────────────────────────────────────────────────────────────┤
│  current_screen: Menu | Submenu | Form | Result | Loading   │
│  selected_index: usize                                      │
│  form_data: HashMap<String, String>                         │
│  cluster_info: ClusterInfo (auto-refresh)                   │
│  wallet_balance: u64 (auto-refresh)                         │
└─────────────────────────────────────────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│                       Event Loop                            │
├─────────────────────────────────────────────────────────────┤
│  1. Poll for keyboard events                                │
│  2. Poll for background tasks (cluster refresh)             │
│  3. Update state                                            │
│  4. Render UI                                               │
│  5. Repeat                                                  │
└─────────────────────────────────────────────────────────────┘
```
